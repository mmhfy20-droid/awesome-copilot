# Visual UI and UX Engineering

## Workflow
1. Confirm the selected visual direction, audience, platform, brand, language, and accessibility needs.
2. Define design tokens: color roles, typography scale, spacing, radii, elevation, borders, and motion.
3. Design reusable components before individual screens.
4. Specify every important state: default, hover, focus, pressed, loading, empty, error, disabled, and success.
5. Design responsive behavior for narrow phones, tablets, and desktop.
6. Support right-to-left and left-to-right layouts when localization requires both.
7. Use semantic HTML, keyboard navigation, visible focus, sufficient contrast, and reduced-motion preferences.
8. Validate visual consistency across the complete journey, not only the home screen.

## Visual quality
- Use hierarchy, whitespace, alignment, and restrained accent colors.
- Avoid generic template layouts and decorative motion that harms usability.
- Use animation sparingly: short transitions, subtle feedback, and no continuous motion that distracts.
- Keep text readable and controls touch-friendly.
- Use real product content where available; clearly label placeholders.

## Deliverables
- Design tokens and component inventory
- Screen-by-screen layout specifications
- Responsive and RTL rules
- Interaction and accessibility state checklist
- Visual QA findings with exact screen/component references

## Guardrails
Do not claim WCAG conformance without testing. Do not fabricate product images, ratings, reviews, or medical claims.
